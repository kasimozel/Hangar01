# Hangar01

**Unity Sürümü:** Unity 6.3 LTS

Nu.D.36'dan esinlenen low-poly çift kanatlı uçak modeli ve Rota 02 vektör uygulamalarını içeren Unity laboratuvar projesi.

## Rota 02

- Uçağın hedefe doğru normalize yön vektörüyle ilerlemesi
- Hedefe doğru yumuşak dönüş
- Dış çarpım (Cross Product) kullanılarak dönüş yönünün belirlenmesi ve uçağın yatış yapması
- İç çarpım (Dot Product) kullanılarak uçaksavarın görüş konisi kontrolü
- Radar menzil ve görüş açısı kontrolü
- Vektörlerin ve radar görüş alanının Gizmos ile Scene görünümünde gösterilmesi
